# SmartClass — Class Improvements (planned)

Agreed to keep (2026-10-20). Not built yet. See also `AI_PLAN.md` (AI features)
and `FEATURE_NOTES.md` (email, multi-teacher).

---

## 1. Private comments

**Today** private comments exist only on assignments:
- **Student:** a "Private comments" card under their work on the assignment page.
- **Teacher:** a small collapsed "Private comments (n)" link inside each student's
  row in the submissions table — easy to miss, and the teacher has to open every
  assignment to find new messages.

**To add**
1. **Teacher private-comment inbox** — a **Messages** tab per class listing every
   private thread across all assignments, newest first, with **unread** marks, a
   reply box, and a link to the assignment.
2. **"Message teacher" for students** — a private conversation with the teacher
   about the class in general, not tied to an assignment. The teacher replies from
   the same Messages tab.
3. **Private comments on quizzes** (e.g. "I had a problem during the quiz").
4. **Unread-message count** on the class card and the notification bell.

---

## 2. Class page

**Overview strip at the top**
- Teacher: students, class average, today's attendance (taken or not), work to
  grade, join requests.
- Student: my grade, my attendance %, missing work, next due item.

**Stream**
- Edit a post (today it can only be deleted).
- Attach links or files to posts.
- Schedule a post for later.

**Classwork**
- A **"Due this week"** section at the top.
- Students mark a lecture or resource as **done**; the teacher sees who opened
  each lecture.
- Attach a resource or link to an assignment.
- Search, and collapse / expand topics.

**Calendar tab**
- Month view of every due date (assignments, quizzes) and attendance days.

**People**
- Export the roster to CSV.
- Each student's last activity and overall grade in the list.

**Grades**
- Grade straight from the gradebook (click a cell).
- Colour scale for low and high scores; sort by column.

1. Private-comment inbox + "Message teacher"
